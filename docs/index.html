Representar texto

Unicode amplía la representación a los sistemas de escritura del mundo

  • Universalidad: busca incluir caracteres de múltiples lenguas y sistemas simbólicos.
  • Uniformidad: cada carácter recibe un punto de código bien definido.
  • Unicidad: un mismo carácter debe tener una identificación consistente.
  • UTF‑8 usa entre 1 y 4 bytes por carácter.
\[\mathrm{A}\longrightarrow \mathrm{U{+}0041}\longrightarrow 01000001_2\]
\[\mathrm{ñ}\longrightarrow \mathrm{U{+}00F1}\]
\[\pi\longrightarrow \mathrm{U{+}03C0}\]
\[\text{你}\longrightarrow \mathrm{U{+}4F60}\]

El número representado no es el significado: es un código acordado para almacenar, transmitir y recuperar el símbolo.

Fundamento matemático

Los números naturales pueden caracterizarse mediante los axiomas de Peano

\(0\in\mathbb N\)Existe un primer natural.
\(S(n)\in\mathbb N\)Cada natural tiene sucesor.
\(S(n)\neq0\)El cero no es sucesor.
\(S(n)=S(m)\Rightarrow n=m\)El sucesor es inyectivo.
InducciónUna propiedad que vale en 0 y se conserva por sucesor vale en todo ℕ.

Los enteros pueden construirse como clases de equivalencia de pares de naturales

\[[(a,b)]\longleftrightarrow a-b.\]

\([(5,2)]=3\) y \([(8,5)]=3\); ambos pares son equivalentes.

Datos

Medimos una longitud alrededor de la naranja

d ≈ 2πr
\[r\approx\frac{d}{2\pi}.\]

La medición introduce incertidumbre y la naranja no es una esfera perfecta.

Relación entre cantidades

Cantidad de interés y ley constitutiva

En ocasiones, una relación de este tipo se denomina modelo constitutivo o ley constitutiva: conecta variables observables con una cantidad de interés.

Geometría
\(v=\frac{4\pi}{3}r^3\)
→
Relación general
\(q=F(v,\alpha,\beta,\ldots)\)
→
Modelo simple
\(q=\alpha v\)

α resume, de forma muy simplificada, la fracción de volumen que corresponde a jugo.

Modelo continuo

Modelo continuo, exacto o teórico

\[q=\alpha v=\alpha\frac{4\pi}{3}r^3.\]
\[r=\frac{d}{2\pi}.\]
\[q=\frac{\alpha d^3}{6\pi^2}.\]

La expresión es exacta dentro del modelo idealizado. Al implementarla, aparecen aproximaciones numéricas y redondeo.

Cálculo computacional

Implementación con dos decimales

\[\alpha=0.7,\qquad d=21\,\mathrm{cm}.\]
\[q\approx\frac{0.7(21)^3}{6(3.14)^2}.\]
\[q\approx\frac{6482.7}{59.16}.\]
\[q\approx109.58\,\mathrm{cm}^3.\]

La máquina redondea cada cantidad a dos cifras decimales.

¿Es lo mismo redondear cada operación que redondear solo el resultado final?

Síntesis del modelo

Modelo resultante

\[p=\frac{d}{2\pi},\qquad v=\frac{4\pi}{3}p^3=\frac{d^3}{6\pi^2},\qquad q=\alpha v=\frac{\alpha d^3}{6\pi^2}.\]
